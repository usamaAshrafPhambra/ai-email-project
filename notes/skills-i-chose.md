# Skills I chose

Searched skills.sh on 2026-11-12 with `npx skills find` for: email marketing, email sequence, campaign plan, resend. GitHub stars were checked the same day.

## Use these

1. **Anthropic's marketing plugin** (`anthropics/knowledge-work-plugins`): for planning campaigns and writing emails.
   - Official publisher (Anthropic, the makers of Claude). The GitHub repo has about 35,500 stars.
   - It has the exact skills this studio needs: `campaign-plan` (3.4K installs), `email-sequence` (3.1K installs) and brand review.
   - Its install counts are lower than some community skills, but the stars and the publisher are what count.

2. **Resend's own skills** (`resend/resend-skills`): for sending email.
   - Official publisher: Resend, the email service we connect to later. Skills: `resend` (24.5K installs), `resend-cli` (14K installs).
   - Stars are modest (about 210), but it's the company that runs the service, so it will match how Resend actually works.
   - Related, also from Resend: `resend/email-best-practices` (about 150 stars).

## Avoid these

1. **`caffeinelabs/skills@extension-email-marketing`**: 31.2K installs, but its GitHub repo has only **2 stars**. A huge install count with almost no stars suggests the installs are inflated or automated. The publisher isn't known.

2. **`samber/dev-event-organizer-skills@event-attendee-email-sequences`**: 6.6K installs, but only **4 stars**, from a personal account. Same warning sign. It's also made for event attendees, not a product launch.

Honourable mention: `coreyhaines31/marketingskills` is popular and well-starred (about 59,800 stars), but it's one person's collection, not an official source. Its email skills are also being reorganized: `email-sequence` (55.1K installs) and a newer `emails` (87.3K installs) both show up, so check which one is current before using it.

## How I decided

1. **Who publishes it?** Prefer official publishers (Anthropic, or the company whose service the skill uses) over unknown accounts.
2. **Do the GitHub stars match the installs?** Install counts can be faked. Thousands of installs with only a few stars is a red flag.
3. **Is it current and does it fit?** Open the skill's page or repo folder. Check that it hasn't been renamed, merged or removed, and that it does what I need.
